# jolly-timber-tool

gRPC · PostgreSQL · Python

日常脚本的集中地

## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/jolly-timber-tool.git
cd jolly-timber-tool
npm install
```
